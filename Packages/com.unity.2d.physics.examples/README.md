# 2D Physics Core (Examples)

2D Physics Core (Examples) is an **unsupported** and **experimental** package that contains example components built on top of the 2D Physics Core package, using only its public API.

The components exist to demonstrate how to build your own components on the public API. They are not production code and are not fully featured.

> **Warning:** This package is unsupported, experimental, and subject to change at any time. Its contents may change or be removed without notice, and no backwards compatibility is guaranteed. Do not depend on it in production.
